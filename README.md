## Ecommerce Website — Business Landing Page

A responsive single-page website built with vanilla HTML, CSS, and JavaScript. No frameworks, no build tools just pure front-end fundamentals.

## Tech Stack
- HTML5 — semantic structure, sectioned layout
- CSS3 — Flexbox-based layout, custom hover/active states, gradient theming, smooth scrolling
- JavaScript (vanilla) — DOM manipulation, event listeners, scroll-based navigation

## Setup

No dependencies or build steps. Clone the repo and open index.html directly in a browser.
